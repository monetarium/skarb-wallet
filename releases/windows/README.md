# Skarb Wallet for Windows

Download: [Skarb Wallet 0.1.5](https://github.com/monetarium/skarb-wallet/releases/download/v0.1.5/Skarb-Wallet-0.1.5-windows-amd64.zip)

64-bit Windows executable.

[SHA-256 checksums](https://github.com/monetarium/skarb-wallet/releases/download/v0.1.5/SHA256SUMS-0.1.5.txt).

## Install

1. Extract `Skarb-Wallet-0.1.5-windows-amd64.zip`.
2. Open the extracted `Skarb-Wallet-0.1.5-windows-amd64` folder.
3. Double-click `skarb.exe`.
